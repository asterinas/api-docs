pub(crate) fn get_tdx_mr_refresh(reg: MeasurementReg) -> Result<[u8; 48], Error>
Expand description

Refreshes the TDX report and returns the requested measurement register value.

Issues a TDG.MR.REPORT TDCALL and then reads reg from the newly generated report. The refresh and the read are performed atomically under the write lock, so the returned value is guaranteed to reflect the hardware state at the time of the call.

Use this function after extend_tdx_mr to observe the updated RTMR value. If no extend has occurred and the cached report is still current, the cheaper get_tdx_mr can be used instead.
