sys_futimesat 🔒
The ‘sys_futimesat’ system call sets the access and modification times of a file. Unlike ‘sys_utimensat’, it receives time values in the form of timeval structures, and it does not support the ‘flags’ argument.

The ‘sys_utime’ system call is similar to ‘sys_utimes’ but uses the older ‘utimbuf’ structure to specify times.

The ‘sys_utimes’ system call sets the access and modification times of a file. It receives time values in the form of timeval structures like ‘sys_futimesat’, but it uses the current working directory as the base directory.
