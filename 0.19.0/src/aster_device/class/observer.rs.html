9/// An observer of devices joining or leaving a class.
10///
11/// An observer is notified when devices join or leave the class
12/// through [`on_device_added`] and [`on_device_removed`], respectively.
13/// When the observer is registered or unregistered,
14/// the corresponding callback is also called for every device currently in the class.
15/// Each device is announced once, regardless of whether it or the observer is registered first.
16///
17/// Callbacks are serialized with changes to this class's devices and observers.
18/// To avoid deadlocks, callbacks must not add or remove devices in this class,
19/// register or unregister observers of this class,
20/// bind or unbind bus devices, or read or write driver attributes.
21/// Queue such work for another thread and return without waiting for it.
22///
23/// Typical uses include:
24///
25/// - **Partition discovery.**
26///   An observer of the `block` class can schedule disk scans and registration of partition devices.
27/// - **Console selection.**
28///   An observer of the `tty` class can track available terminals for console selection.
29///
30/// [`on_device_added`]: `Self::on_device_added`
31/// [`on_device_removed`]: `Self::on_device_removed`
32pub trait ClassObserver<C: Class>: Send + Sync + 'static {
33    /// Handles a device joining the class or being announced when this observer is registered.
34    fn on_device_added(&self, dev: &Arc<ClassDevice<C>>);
35
36    /// Handles a device leaving the class or this observer being unregistered.
37    fn on_device_removed(&self, _dev: &Arc<ClassDevice<C>>) {}
38}
