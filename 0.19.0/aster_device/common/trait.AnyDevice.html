Expand description

An interface shared by all devices.

Use dyn AnyDevice to inspect devices without knowing their concrete bus or class type. [SysBranchNode] provides access to its sysfs attributes and child nodes. Creating or removing children through [SysBranchNode] is unsupported; use add_device and remove_device to manage devices.

Implemented by BusDevice, ClassDevice, and BareDevice. This trait cannot be implemented outside this crate.
