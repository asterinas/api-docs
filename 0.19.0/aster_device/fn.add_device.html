pub fn add_device<D: AnyDevice + ?Sized>(dev: &Arc<D>) -> Result<()>
Expand description

Registers a device, publishing its sysfs directory and optional /dev node.

The device’s sysfs attributes and links are available before its bus probes for a driver or its class notifies observers. Device-node creation is queued until the kernel hooks are installed.

On failure, registration is rolled back and the device cannot be added again.
