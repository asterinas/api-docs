pub fn relative_path(from_dir: &str, to: &str) -> String
Expand description

Computes the relative path from the directory from_dir to the target to.

Both arguments are absolute paths within one SysTree as returned by SysObj::path (the root is /). The result is suitable as the target of a symlink placed inside from_dir, e.g. the relative path from /class/mem to /devices/virtual/mem/null is ../../devices/virtual/mem/null.

The result always ends with the last component of to, as the symlinks in Linux’s sysfs do: the relative path from /devices/a/b/c to /devices/a is ../../../a, not ../...
