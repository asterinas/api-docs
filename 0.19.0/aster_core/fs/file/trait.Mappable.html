Expand description

A trait that describes memory mapping behavior for special files (in mmap).

Required Methods§

Source

fn map( &self, offset: usize, handle: MapHandle<'_, '_, '_>, ) -> Result<Box<dyn MappedObject>>

Fills the memory region to map with handle.

offset specifies the file offset, which must be page-aligned.

This method may fail after some pages have already been installed through handle. In this case, the caller should remove those pages and destroy the memory mapping.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
