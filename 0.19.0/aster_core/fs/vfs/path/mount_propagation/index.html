Mount-event propagation state and topology.

MountPropagation describes how one mount participates in propagation. Fallible operations prepare new relationships in PendingPropagationChanges and publish them only after the enclosing tree operation succeeds. MountTopology serializes mount-tree changes and indexes the peer and master relationships used to route propagation events.
