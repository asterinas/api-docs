Mount option parsing for overlayfs.

This module validates the mount option string into a MountOptions construction input. The recognized keys are the path keys lowerdir, lowerdir+, upperdir, and workdir, the mode keys uuid and xino, the raw-intent keys redirect_dir, index, nfs_export, metacopy, verity, and fsync, and the valueless keys default_permissions, userxattr, volatile, and nooverride_creds.

Unknown keys fail with EINVAL before any layer state is created. A raw-intent key records an explicitly requested feature that is not implemented: the request is accepted, and the verify phase warns once at mount time that the mount proceeds without that feature.
