fn recvmsg( &self, writer: &mut dyn MultiWrite, flags: RecvFlags, ) -> Result<(RecvOutput, MessageHeader)>

Receives a message from the socket.

If successful, the writer buffer will be filled with the received content. This method returns the length, flags, and header of the received message.
