Graphics Execution Manager (GEM) support.

GEM provides DRM drivers with graphics buffer objects and the core mechanisms needed to expose those objects to userspace. A DrmGemObject owns a driver-provided memory backend, while the DRM core manages per-file handles, mmap access, and device-wide fake mmap offsets.

A driver enables GEM by returning its DrmGemOps implementation from crate::device::DrmDevice::as_gem_ops. Drivers may use shmem::DrmGemShmemBackend for RAM-backed objects or provide their own object::DrmGemObjectBackend implementation.
