Module kms 

Source
Expand description

Kernel Mode Setting support for DRM devices.

This module defines the shared KMS interface exposed by DRM drivers. DrmKmsOps provides device-specific KMS operations, while DrmModeConfig owns the device-wide mode configuration and synchronized KMS object store.

Individual planes, CRTCs, encoders, connectors, and properties are defined in the objects module.
